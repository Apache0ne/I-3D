Stage 0: Background removal

Run actual ONNX background segmentation with ONNX Runtime Web's WebGPU execution provider. Outputs are an alpha mask and transparent full-resolution PNG for the next I-3D stage.

The input is normalized with ImageNet mean/std at 1024 × 1024. Only the original image and output mask/PNG travel into the I-3D workspace. Model weights are downloaded directly to your browser; they are not added to GitHub.

Licensing: RMBG 2.0 is distributed under CC BY-NC 4.0; commercial deployment requires BRIA permission. The default model is an independently patched export fixing WebGPU Split/Concat shader-binding limits. The model you linked is available as an alternative but its unmodified ONNX may fail on WebGPU.

Output actions

Workspace saving works when this page is served by I-3D's Colab viewer server. Standalone localhost uses the download buttons. After saving, the branch notebook can use the transparent PNG for geometry and the original source for painting.
