Real data tool: upload depth PNG

Upload your depth map (8-bit grayscale encoded in its red channel). Red channel 0–255 is mapped to 0.3–2.3 m; fully transparent pixels are excluded. This is a format converter, not depth estimation.

Architecture

Standalone WGSL operators are kept separate from a cached dispatch runtime. Tensor uploads, quantized weight decoding, camera transforms, skinning, geometry and shading are explicit. A full Hi3D/Hunyuan model port requires additional weights, diffusion graph execution and memory planning; this branch does not claim those models currently run here.

On-device correctness suite

Each operator runs on your actual WebGPU adapter and is checked numerically against an independent CPU implementation. No TensorRT, CUDA or Python dependency. The microbenchmark reports end-to-end host transfer + GPU + readback time, not pure shader duration.
